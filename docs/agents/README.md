# Документы агентских прогонов

Здесь лежат спеки, реверс-разборы эталона, отчёты по стенду и снимки доказательств,
которые делались при переносе поведения AGVControl в `VR.RoutePlanner`.

Папки по датам и темам:

| Папка | Содержание |
|---|---|
| `2026-11-20-stage1-graph` | этап 1: граф карты |
| `2026-11-20-stage1-tail` | этап 1: хвост задач |
| `2026-11-21-stage1.5-contracts` | этап 1.5: контракты, снимок Swagger AGVControl |
| `2026-11-21-stage2-planner` | этап 2: планировщик |
| `2026-11-21-stage2.5-vda` | этап 2.5: VDA-заказ, первый вариант |
| `2026-11-23-stage2.5-vda-port` | этап 2.5: порт шага 3 |
| `2026-11-24-agv-robot-control` | поведение робота и вил, эталоны заказов, разбор зависания, `handover.md` |
| `2026-11-27-parking-charging` | автозарядка и автопарковка: спека, разбор эталона, отчёт по стенду |

Начинать знакомство с проекта стоит с `2026-11-24-agv-robot-control/handover.md`:
там состояние порта, правила формы заказа, порты стенда, сборка симулятора
и список открытых вопросов.

Внутри каждой темы обычно есть:

- `spec*.md` - спека с решениями и критериями приемки;
- `reverse*.md` - разбор кода AGVControl и симулятора со ссылками `file:line`;
- `evidence/` - снимки MQTT-сообщений, вывод тестов, скрипты прогонов, отчеты по стенду.

Документы исторические: пути `C:\Projects\VRouter\doc\agents\...` в старых текстах
указывают на прежнее расположение, сейчас актуальна эта папка.
